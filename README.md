How to install:


Execute 'wget https://cubehub-studio.github.io/CC-Moon-BIOS/startup'

Execute 'wget https://cubehub-studio.github.io/CC-Moon-BIOS/updatemoonbios'

Execute 'reboot'


How to update:


Press one during boot ( if an OS is installed, it will boot BIOS automatically if you dont )

Enter CC Shell

Execute 'updatemoonbios'
